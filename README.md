# MAVI — Painel (produção)

Este é o repositório de **produção** do painel da MAVI Centro de Estética.

- Editado ao vivo pelo [Lovable](https://lovable.dev) — por isso o histórico tem
  muitos commits genéricos ("Changes", "Work in progress").
- Conectado à Vercel: todo push em `main` dispara deploy automático.
- É este código que a Marina e as clientes realmente usam no dia a dia.

## Repositório separado (não usar para produção)

Existe outro repositório, `morgckummer-debug/maviestetica`, que **não está
conectado à Vercel**. Mudanças feitas só lá **não aparecem no site**.

Antes de começar qualquer tarefa — correção, funcionalidade, o que for —
confirme que está trabalhando **neste** repositório (`estetica-mavi-3`).
